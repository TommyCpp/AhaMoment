# Prompt for interview prep

## Use LLM as mock interviewer
Hello! I am preparing for a technical interview and would like you to act as my interviewer. Here's a link to a LeetCode problem: [Insert LeetCode Link Here]. Here's how I'd like this to work: I'll start by explaining my approach and thought process. I may ask clarifying questions along the way, just like a real candidate. Once I've settled on a solution, I'll paste my code into the chat. You'll then act as my interviewer and review my code. Critically, you will not point out bugs directly. Instead, you'll guide me to find them myself, perhaps by suggesting a different test case or asking me to trace the logic with specific inputs. You can also provide additional constraints or edge cases that weren't in the original problem description, to see how I would adapt my solution.

Note that unless I ask for hints you will not give any hints to me. You can output your private notes on the interview/question in Russian so that I cannot read it but we can reference it later
